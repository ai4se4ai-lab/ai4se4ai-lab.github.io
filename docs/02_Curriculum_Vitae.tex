\section{Research Profile}
My research focuses on making AI-assisted software engineering reliable and its results checkable. My recent work develops verifiable agent skills and traceable agent coordination (SkillSpec, AgentM2M, AutoM2M), alongside checked experimental infrastructure (use-hpc, RES-AI). Complementary projects use evidence from code repositories and execution traces to support software testing, maintenance, and diagnosis. Explicit contracts and provenance connect these projects by making automated decisions easier to validate and failures easier to explain.
